# `KeepPressing`

Windows mouse and keyboard automation with global hotkeys.

## Install

Download the ZIP from the [release page](https://github.com/P4suta/keep-pressing/releases/latest), then unzip the entire folder.
Keep the root `KeepPressing.exe` and its `app/` folder together.

## Use

1. Open the root `KeepPressing.exe`.
2. Choose a mouse button or keyboard key, Repeat or Hold, and the interval.
3. Focus the target app and press **F6** to start or stop.

The [usage and build guide](docs/usage.md) covers fixed-position capture, other hotkeys, limitations, and development.
See the [release process](docs/RELEASING.md) for maintainers.
